# WP Database Optimizer

Optimize and clean your WordPress database by removing revisions, auto-drafts, orphaned meta, and expired transients.

## Features

- Admin dashboard showing total database overhead and items to clean.
- One-click actions for Revisions, Auto-drafts, Orphaned Post Meta, and Expired Transients.
- Settings page to schedule daily auto-cleanup.
- Logs view showing history of cleaned items.
- Safe installation and uninstallation, removing its own tables when uninstalled.

## Installation

1. Upload the `wp-database-optimizer` directory to the `/wp-content/plugins/` directory, or install the ZIP file via the WordPress plugins page.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to **DB Optimizer** in the admin menu to manage your database cleanups.
